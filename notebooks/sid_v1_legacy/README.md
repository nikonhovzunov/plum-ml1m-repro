# SID-v1 Legacy

The first SID-v1 experiments used an earlier five-level Semantic ID prototype
and are not part of the active SID-v2 protocol. Heavy notebooks from that phase
were removed from the public tree because they duplicated obsolete logic and
contained large executed outputs.

The only retained public reference is the metric row in the root README:
`SID-v1 first retrieval attempt`, `Recall@10 = 0.0253`.

# Reports

This directory contains compact, committed metric snapshots for the results
reported in the project documentation.

Only small JSON/CSV files are allowed here. Full prediction dumps, checkpoints,
adapters, embeddings, processed datasets, and large generated reports remain
outside git.

See:

- `schema.md` for the snapshot format.
- `snapshots/summary_test.csv` for held-out test rows.
- `snapshots/summary_validation.csv` for validation rows.
- `docs/RESULTS_PROVENANCE.md` for row-level provenance notes.
